# Estrutura do projeto

```text
├── api/                  # Backend Node.js, Prisma e SQL Server
├── frontend/
│   ├── admin/             # Login e painel administrativo
│   ├── assets/            # Imagens e identidade visual
│   ├── scripts/           # JavaScript do front e painel
│   └── styles/            # CSS do painel
├── dc-transportes.html    # Página principal
├── obrigado.html          # Página de confirmação
├── iniciar-projeto.cmd    # Inicia front e back
└── parar-projeto.cmd      # Encerra front e back
```

O inicializador usa Node/npm para servir o front; Python não é necessário.
